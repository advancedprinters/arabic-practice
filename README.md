# Project Two — Language Coach

Project Two is the user's separate language-learning app project.

Current live app: Arabic Coach, hosted from this repository with GitHub Pages.

## Scope
- Keep Project Two completely separate from Project One.
- Current language: Arabic.
- Designed to expand to additional languages later.
- Core features include learning cards, pronunciation/audio, slow playback, translation practice, quizzes/challenges, saved phrases, and progress tracking.
- Future upgrades can add multiple selectable languages while preserving the same app framework.

## Repository
This repository (`advancedprinters/arabic-practice`) is the home of Project Two.

Do not use or modify the Project One repositories for Project Two work.
